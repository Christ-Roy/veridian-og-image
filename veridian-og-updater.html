Mise à jour des métadonnées OpenGraph pour Veridian

Cet outil vous permet de mettre à jour facilement l'aperçu de votre site web lorsqu'il est partagé sur les réseaux sociaux

Étape 1: Aperçu actuel vs nouvel aperçu

Voici comment votre site apparaît actuellement lorsqu'il est partagé sur les réseaux sociaux :

Aperçu actuel
veridian-local-boost
Lovable Generated Project

Et voici comment il apparaîtra après la mise à jour :

Nouvel aperçu
Veridian - Création de sites web pour commerces locaux
Transformez les visiteurs en ligne en clients réels pour votre commerce. Votre site commence ici, gratuitement.

Étape 2: Installer les métadonnées OpenGraph

Vous avez deux options pour installer les métadonnées OpenGraph :

Option 1: Installation temporaire (pour test)

Cliquez sur le bouton ci-dessous pour installer temporairement les métadonnées OpenGraph sur cette page. Cela vous permettra de tester l'aperçu, mais les modifications ne seront pas permanentes.

Installation temporaire réussie ! Les métadonnées sont maintenant actives sur cette page.

Option 2: Installation permanente (recommandé)

Pour une installation permanente, vous devez ajouter le code suivant dans la section <head> de votre site web :

<!-- Métadonnées OpenGraph pour l'amélioration de l'aperçu sur les réseaux sociaux -->
<meta property="og:title" content="Veridian - Création de sites web pour commerces locaux" />
<meta property="og:description" content="Transformez les visiteurs en ligne en clients réels pour votre commerce. Votre site commence ici, gratuitement." />
<meta property="og:type" content="website" />
<meta property="og:image" content="https://raw.githubusercontent.com/Christ-Roy/veridian-og-image/main/veridian-og-final.png" />
<meta property="og:url" content="http://veridian.site/" />

<!-- Métadonnées Twitter Card -->
<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content="Veridian - Création de sites web pour commerces locaux" />
<meta name="twitter:description" content="Transformez les visiteurs en ligne en clients réels pour votre commerce. Votre site commence ici, gratuitement." />
<meta name="twitter:image" content="https://raw.githubusercontent.com/Christ-Roy/veridian-og-image/main/veridian-og-final.png" />
Code copié dans le presse-papiers !

Étape 3: Vérifier l'installation

Une fois les métadonnées installées, vous pouvez vérifier qu'elles fonctionnent correctement en utilisant les outils suivants :

Validateur OpenGraph de Facebook Validateur de cartes Twitter Inspecteur de liens LinkedIn

Note importante : Les réseaux sociaux mettent en cache les métadonnées OpenGraph. Si vous ne voyez pas les changements immédiatement, utilisez l'option "Actualiser les informations" ou "Fetch new scrape information" dans les outils de validation.
